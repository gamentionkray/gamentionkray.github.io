# Theme worlds: experience contract
User request: completely revamped layouts based on each theme, with unique fun interactions. Confirmed preference: fully immersive.
Preserve every existing theme URL, current factual résumé content, downloadable PDF, portrait, accessible theme picker, phone support.
The 44 existing named themes are the pinned visual directions. Their form and interaction take precedence over the generic direction seed, which returned a degraded result with no catalogue challengers. Code-led implementation of those explicitly named worlds.
First viewport: demonstrate each world's native mechanism immediately: an editable terrain in Minecraft; planetary buttons in Cosmic; project ability bar in Dota; research-paper margins in Scientific; a dense masthead/lead story in Newspaper; desktop apps in Aero/Vaporwave/Skeuomorphic; a project shell in Terminal; project quest journal in RPG. Other themes follow their own corresponding form documented in data/themes.json.
Signature interactions: every route has its own functional control or disclosure system; meaningful project selectors render real project facts. No fake analytics, star ratings, level scores, status claims or autoplay audio. Pointer controls have keyboard or native-control alternatives except optional freehand drawing. All portfolio facts remain available without JavaScript.
Motion: theme-specific and bounded, no mandatory waiting. Reduced-motion disables decorative animations, shell scrolls and reader transitions. All text starts visible.
Shared building blocks are text/data atoms, not a shared hero or a single content flow. Worlds own page-level structure, project browsing, lower record grammar and navigation. Common isolated picker uses real screenshots, fixed contrast, search, category filters and focus handling.
